> README // WHAT THIS IS NOT ▸

The idea

The version the Global Consciousness Project actually measured: coherence across a network of independent generators. It never mattered what a generator "meant" — only that it was an independent source sampled continuously. So this is a swarm of independent entropy arms, each drawn fresh every second, watched for the moment they agree more than independence allows.

The live tier — what the statistic runs on

Algorithmic / null controls: a CSPRNG plus five separately-seeded PRNGs (xorshift, PCG, splitmix, mulberry, Lehmer). They are deterministic, so they cannot carry a real anomaly — they are distributed null controls. Physical detectors: CPU/clock timing jitter, the phone motion sensor (opt-in), the arrival-timing jitter of the Wikipedia / Bluesky / Mastodon firehoses (when each event lands, not its content), drand quicknet, and the Coinbase trade tape. Every arm contributes to an epoch only when it has genuinely new data — no stale value is ever re-counted.

The metric

Each second, over the arms with a fresh draw: Z = Σzᵢ/√N, coherence c = Z² (χ²₁, mean 1 under independence). The walk is Σ(c−1); session significance Zc = Σ(c−1)/√(2N) ≈ N(0,1). The same is computed separately for the physical subset (detectors) and the algorithmic subset (controls).

The context ring — kept, but outside the math

Solar wind, seismic, barometric, tide, river, air quality, ocean swell, NIST, Hacker News and GitHub update every few minutes — far too slow for a 1 Hz statistic, where they'd just be one frozen value re-counted hundreds of times. So they ride alongside as honest, timestamped context and never touch the coherence number. (Browser-hostile ones flag "may need proxy.")

The one rule, and what this is NOT

Every arm must be an independent draw — never arm B derived from arm A; that single mistake manufactures fake coherence. It measures coincidence, not meaning — Jung's synchronicity is what an observer reads into a coincidence; no instrument supplies that. And run long enough and you will cross p<0.05 ~1 session in 20 by chance — calibration, not a message. The "glitch" is theatre for a spike; the verdict text stays honest.
